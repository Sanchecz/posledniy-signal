# Последний сигнал

Мобильная интерактивная новелла-кликер о станции «Ноктюрн». Игрок накапливает эхо, усиливает сигнал, открывает анимированные сцены и выбирает ответы, которые развивают Близость, Авантюризм или Тайну и приводят к разным концовкам.

## Что входит в релиз

- 12 сюжетных сцен и 10 развилок с двумя-тремя вариантами ответа;
- 7 достижимых концовок: три редкие концовки пути, три смешанные и секретный сбалансированный финал;
- многослойные SVG-иллюстрации с параллаксом, частицами, светом, движением персонажей и отдельным режимом `prefers-reduced-motion`;
- полноценный clicker/idle-цикл: ручной импульс, серии, критические срабатывания, 7 модулей, пассивный и офлайн-сбор;
- выборы, которые нельзя применить повторно или переписать случайным касанием;
- разветвлённые реплики Миры, зависящие от накопленных характеристик;
- Новая игра+ через резонанс: экономика сбрасывается, решения и отношения сохраняются;
- versioned-сохранение, миграция старых форматов, PWA и автономный запуск.

## Стек и архитектура

- vinext 1 beta, React 19 и строгий TypeScript;
- Vite 8 и Cloudflare Worker-совместимая ESM-сборка;
- чистое игровое ядро в `app/game/engine.ts`;
- сюжет, выборы, баланс и пороги сцен в `app/game/config.ts`;
- кодовые интерактивные иллюстрации в `app/StoryScene.tsx`;
- мобильный UI и жизненный цикл сохранения в `app/GameApp.tsx`;
- production-заголовки безопасности в `worker/index.ts`;
- PWA-манифест и service worker в `public/`.

Приложение намеренно не использует D1/R2, аккаунты и аналитику. Прогресс относится к одному устройству и хранится в `localStorage`. Любое сохранение считается недоверенным: числа ограничиваются, неизвестные ключи отбрасываются, ответы сверяются с текущим сюжетным каталогом. Офлайн-доход ограничен 12 часами.

## Основной пользовательский цикл

1. Нажать отдельную кнопку «Послать импульс» и накопить эхо.
2. Купить усиление сигнала или модуль пассивного сбора.
3. Достичь порога следующей сцены.
4. Посмотреть анимированную иллюстрацию и реплику Миры.
5. Выбрать один из двух-трёх ответов.
6. Увидеть непосредственное последствие и получить очки сюжетного пути.
7. Продолжить clicker-цикл до следующей сцены и одного из финалов.

Центральная иллюстрация реагирует параллаксом на движение указателя, но не используется как скрытая кнопка. Все действия доступны через явно подписанную кнопку импульса и карточки ответов.

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

Локальный адрес по умолчанию: `http://localhost:3000/`.

Проверка именно production-сервера:

```bash
npm run build
npm run start
```

## Проверки и сборка

```bash
npm run lint
npm run typecheck
npm run test:unit
npm run build
npm run test:render
npm audit
```

Полный release-gate одной командой:

```bash
npm run check
```

Gate проверяет весь авторский исходный код, строгую типизацию, миграцию и нормализацию сохранений, экономику, порядок развилок, невозможность повторного выбора, достижимость разных финалов, 12-часовой offline cap, синтаксис service worker, production-сборку, серверный HTML, метаданные и защитные HTTP-заголовки.

## Мобильная и доступная версия

- portrait-first компоновка, safe area и крупные цели касания;
- корректная прокрутка на экранах 360×640 и ниже;
- виброотклик и синтезированный звук с явными настройками;
- клавиатурный фокус, семантические подписи и диалоги;
- `prefers-reduced-motion` отключает декоративное движение без удаления контента;
- maskable-иконки, offline shell и установка как PWA;
- адаптация под широкие экраны без растягивания сюжетных карточек.

## Android / Google Play

- автономная Capacitor-сборка: сюжет, графика и сохранения находятся внутри приложения и не зависят от сайта;
- package ID: `com.sanchecz.lastsignal`;
- Android 7.0+ (`minSdk 24`), Android 16 / API 36 (`compileSdk` и `targetSdk`);
- адаптивные и монохромные launcher icons, системный splash screen и safe-area для вырезов;
- системная кнопка «Назад» сначала закрывает модальное окно или возвращает на главный экран;
- cleartext-трафик и Android backup отключены, чувствительные разрешения не запрашиваются;
- release-сборка проходит R8/minification, resource shrinking, Android Lint и JVM unit tests;
- upload key и `keystore.properties` игнорируются Git и должны храниться отдельно.

```bash
npm run build:mobile
npm run android:sync
npm run android:check
```

Для Gradle требуются JDK 21, Android SDK Platform 36 и Build Tools 36.0.0. Подписанный bundle создаётся в `android/app/build/outputs/bundle/release/app-release.aab`.
