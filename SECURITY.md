# Security policy

## Поддерживаемая версия

Поддерживается текущая версия `1.x`. Зависимости должны устанавливаться только через зафиксированный `package-lock.json` командой `npm ci`.

## Модель данных

Приложение не принимает платежи, не собирает персональные данные и не отправляет игровой прогресс на сервер. Данные `localStorage` считаются недоверенными и нормализуются перед использованием. Все числовые поля ограничены конечными неотрицательными значениями, неизвестные ключи отбрасываются.

## Browser security

Production Worker добавляет CSP, HSTS, защиту от встраивания во фреймы, MIME sniffing и ограничение browser capabilities. Локальная разработка освобождена только от CSP/HSTS, чтобы не ломать HMR; остальные заголовки проверяются и локально.

## Сообщение об уязвимости

Не публикуйте рабочий эксплойт в открытом issue. Передайте владельцу проекта шаги воспроизведения, затронутую версию, ожидаемый эффект и минимальный proof of concept приватным каналом репозитория.
